# Mascot artwork

All artwork is served locally. Docker and Go use the portfolio's Nord palette;
Tux retains the original artwork and colors.
Decoration only: no endorsement by the represented projects is implied.

- **Go gopher:** designed by [Renee French](https://reneefrench.blogspot.com/);
  vector by [Takuya Ueda](https://github.com/tenntenn).
  [Original vector](https://github.com/golang-samples/gopher-vector/blob/master/gopher.svg),
  licensed [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
  Adaptation: Nord colors; geometry retained.
- **Docker whale:** [Simple Icons Docker mark](https://github.com/simple-icons/simple-icons/blob/develop/icons/docker.svg),
  [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
  Adaptation: Nord colors, eye, and water line.
  Docker is a trademark of Docker, Inc.
- **Tux:** original Linux mascot by **Larry Ewing**, created with **The GIMP**.
  [Original artwork and permission](https://commons.wikimedia.org/wiki/File:Tux.png).
  The transparent PNG is used unchanged, not redrawn or recolored.
  Permission: “Permission to use and/or modify this image is granted provided
  you acknowledge me lewing@isc.tamu.edu and The GIMP if someone asks.”
